# Independent bandpass and temperature diagnostics (5 November 2026)

Two synthetic analyses independent of the web interface:

1. Integrate Planck spectral radiance over a non-negative, wavelength-sampled energy-response throughput curve, normalized by the throughput integral. This is not photon-counting response; such a detector requires a wavelength weighting factor.
2. Evaluate the derivative of log(two-band flux ratio) with respect to log temperature using a symmetric fractional-temperature perturbation. Near-zero derivative implies poor color-temperature identifiability.

Run from the research directory: `python -m unittest -v test_bandpass_robustness.py` (requires numpy and scipy; numpy >=2 for trapezoid). Four deterministic tests check the Rayleigh–Jeans limit, integration, monotonicity and finite-difference convergence.

No measured filter curves, extinction corrections, stellar spectra or observational data are claimed. Scientific code prepared with AI assistance; Git commit attribution follows the configured repository identity.
